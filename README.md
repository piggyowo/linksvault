# LinkVault · 个人网站收藏库

一个跑在 Cloudflare 免费档上的个人网站收藏库：**一个 Worker + 一个 D1 数据库，零服务器、零月费**。
打开网页就能搜、能存、能导出；还能用 Telegram 机器人随手丢链接收藏。

> 本仓库的目标：**不需要 AI 帮忙，一个人照着文档也能一步步把这套东西原样搭出来。**
> 从零开始请直接看 [部署教程](docs/deploy.md)，跟着做 20 分钟左右就能上线。

## 它能干什么

- **收藏**：标题、网址、分类、备注，新增 / 编辑 / 删除
- **搜索**：按标题、别名、分类、备注模糊搜；按分类筛选
- **预览卡片**：添加时自动抓目标站的标题和 OG 图片 / 简介，卡片左图右文；没图的站显示标题首字母块
- **导入导出**：导入浏览器导出的 HTML 收藏夹或 JSON（按网址自动去重）；
  导出 HTML（可直接喂给 Edge 等浏览器）或 JSON 备份
- **公开只读**：不登录也能看列表、搜东西；写操作（新增 / 编辑 / 删除 / 导入 / 导出）必须登录管理员账号
- **访客密码（可选）**：给别人一个只能看的密码，撤回时改掉密钥即可，访客立刻掉线
- **Telegram 机器人（可选）**：给机器人发链接即自动收藏，支持 `链接 #分类 备注` 语法（见 [机器人搭建](docs/telegram-bot.md)）
- **一键收藏（可选）**：iOS 快捷指令、桌面书签（见 [一键收藏](docs/one-click-save.md)）

## 思路：为什么是 Workers + D1

| 需求 | 选型 | 理由 |
|---|---|---|
| 要存数据、多端同步 | D1（Cloudflare 的免费 SQLite） | 数据在云端，换手机登录也在 |
| 要能登录、能认人 | Worker（后端程序） | 纯静态页面做不了真正的登录鉴权 |
| 不想买服务器、不想付费 | Cloudflare 免费档 | Worker 每天 10 万次请求、D1 每天 500 万行读 / 10 万行写，个人用远远不到上限 |
| 前后端分开太麻烦 | **一个 worker.js 就是全部** | 页面 HTML、API 接口、机器人 webhook 全在这一个文件里，部署 = 上传这一个文件 |

一句话：**前端是店面（你看到的页面），后端是后厨（存数据、验密码的程序），D1 是仓库。**
这个项目把店面和后厨做进了同一个文件，仓库用 Cloudflare 的免费数据库。

## 数据模型

D1 数据库 `linkvault`，一张表 `bookmarks`（完整建表语句见 [schema.sql](schema.sql)）：

| 字段 | 含义 |
|---|---|
| id | 自增主键 |
| title | 标题（添加时自动抓取，抓不到就用域名） |
| url | 网址（去重依据，见下） |
| note | 备注 |
| cat | 分类 |
| tags | 标签（逗号分隔，预留） |
| pinned | 置顶（预留，1 = 置顶） |
| og_image | 预览图 URL（添加时自动抓 og:image） |
| og_desc | 预览简介（添加时自动抓 og:description） |
| created_at / updated_at | 时间戳（秒） |

去重规则：网址先归一化（去掉 `#hash`、去掉末尾斜杠）再比较，同一个网址只存一次，
网页新增返回 409、导入和机器人收藏时自动跳过。

## 权限模型

| 角色 | 怎么登录 | 能干什么 |
|---|---|---|
| public（未登录） | 直接打开 | 看列表、搜索、按分类筛选 |
| guest（访客） | 输访客密码 | 同 public（页面上不显示新增 / 编辑 / 删除入口） |
| admin（管理员） | 输管理员密码 | 全部：新增 / 编辑 / 删除 / 导入 / 导出 |

实现方式：登录成功后服务器发一个 `lv_auth` Cookie，值 = `SHA256("linkvault\|角色\|密码")`，
每次请求后端重新算一遍比对。密码本身只存在 Worker 的机密变量里，不在代码里。
登录防爆破：同一 IP 5 分钟内输错 5 次，锁定 10 分钟。

## 部署前唯一要改的一处

`worker.js` 顶部有个 `SITE_URL`，把它改成你自己的收藏夹地址（机器人回复里用；不接机器人可以不管）。

## 免费额度（Cloudflare 免费档，2026 年）

- Worker：每天 10 万次请求（静态文件请求不计）
- D1：每个库 ≤ 500MB、全账号 ≤ 5GB；每天 500 万行读 / 10 万行写
- 超限当天服务暂停到 UTC 0 点重置，数据保留，不扣费
- 现在只占 1 个 Worker + 1 个 D1，再开几个个人小项目也远不到上限
