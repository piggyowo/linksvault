它能做什么

收藏、整理、找回，一个页面全搞定

🔖

一键收藏

浏览器分享菜单、Telegram 机器人，看到好东西随手丢进来，不打断阅读。

🖼️

预览卡片

自动抓标题、简介和封面图，收藏夹不再是一堆干巴巴的链接。

🔍

秒搜

标题、备注、分类都能搜，几百条收藏也能一下找到。

🤖

机器人同步

Telegram 发的链接和网页是同一个库，两边天然同步，不用来回导。

📥

导入导出

导出 HTML 喂给 Edge，JSON 备份随时带走；导入旧收藏自动去重。

🆓

全免费

Workers + D1 免费档就能跑，数据存在你自己的库里，不寄人篱下。

看它怎么用

三步，从"以后再看"到"随时能翻到"

1

发链接

网页上新增，或者 Telegram 发给 @Capylink_bot，格式是「链接 #分类 备注」。

2

自动整理

机器人抓预览、贴分类，重复链接会提醒你，收藏夹永远不乱。

3

随时翻

打开收藏页，搜索、按分类浏览，想看的东西一直都在。
